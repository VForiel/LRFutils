# 📚 API reference

Every public function, with its parameters and an example. Import the modules from the package:

```python
from LRFutils import archive, color, logs, pltedit, progress, term
```

| Module | What for |
|---|---|
| {doc}`archive` 🗃️ | Dated, self-describing run directories |
| {doc}`pltedit` 🎨 | Editable `.plt` matplotlib figures |
| {doc}`progress` ⏳ | Progress bars with an ETA |
| {doc}`logs` 📝 | Messages printed and written to a log file |
| {doc}`color` 🌈 | Coloured terminal text |
| {doc}`term` 📏 | Terminal width and separators |
